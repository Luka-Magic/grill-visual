## 質問票(render.py)variant D のレイアウト

- 幅 780px 中央、padding 36px 32px、縦 gap 24px。下は送信バーぶん padding-bottom 150px(open がなければ 40px)
- **ヘッダ**: 上段 Mono 12px で左 topic(mute)・右 状態ピル「● Round n / 質問 m 件」(open なら sWait、完了なら sDone)。
  h1 26px/600。intro は sub 14.5px
- **設計ツリー**: panel 背景・line2 枠・radius 8・padding 16 20。見出し行「設計ツリー」+ 右に「● 決定 n / ○ 未決 n」(12px sub)。
  ノードは 8px ドット(done = done 色で塗り、open = wait 色の枠だけ)+ ラベル(done は sub、open は text)+ note(mute 12.5px)。
  子は左 18px に line の縦線
- **タブ**: 下線式。gap 20、border-bottom line。アクティブは text + accent の 2px 下線、他は mute。
  ラベルの右に小さな印: answered = ✓(sDone 色)、open = ●(sWait 色)
- **前提事実**: 破線 line 枠・radius 8・padding 14 18。見出し「前提事実」+「AI 調査済み」(mute)。項目は「・」+ 文(sub)
- **問いカード**: panel 背景・line2 枠・radius 8・padding 22 22 20・gap 14。
  上段 12px: Q 番号(Mono 600 accent)+「複数選択可」(sub、line 枠)+ 右端「✓ 回答済み」(done)。
  h3 17.5px/600、本文 14px sub。選択肢の上に「1 つ選びます / 複数選べます」(mute 12px)
- **選択肢ボタン**: grid `28px 1fr auto`、gap 12、radius 8、padding 11 14 11 12、枠 1.5px。
  左に 26px のキー枠(単一選択は丸、複数は角 4px。未選択: line 枠 + sub 文字、選択: accent 塗り + onAccent 文字、回答済み選択: done 塗り)。
  選択で枠 accent・背景 selBg・文字 600。回答済みの未選択は opacity .55。hover(未選択・open)は枠 mute・背景 hover。
  推奨は右端に「● 推奨」(done 色 12px 600)。**open のときは最初の推奨選択肢の中に推奨理由を 12.5px sub で表示**し、
  回答済みのときはカード下に「推奨理由」行として出す
- 「AI 注記」(review 色のラベル)・「あなたのメモ」(ラベル)は `ラベル + 文` の横並び 13.5px
- メモ欄: input 背景・line 枠・radius 6・1 行から `field-sizing: content` で伸びる(resize なし)
- **宣言事項**: 前提事実と同じ破線枠。info ラウンドでは見出し「合意サマリ」
- **送信バー**(固定下部): bar 背景・line 上線・padding 12 32。中は 780px。
  左に 88px の進捗(Mono 12px「n / m 回答」+ 4px バー accent)、中央に Mono 12.5px の回答文字列(input 背景、ellipsis)、
  右に「+ 自由記述」(sub、押すと上に textarea)・「推奨で埋める」(done 色)・「コピー」(line 枠)・「送信」(accent 塗り 600。送信済みは line2/mute)。
  状態メッセージは右寄せ 12.5px(エラーは err)
- 画像付き選択肢の 3 列 grid と、ルール一覧型(`type: rules`)は上のトークンで同じ調子に合わせる
  (リスク: high = err / mid = wait / low = done、採用トグル = done、不採用は取り消し線 + mute)

## 統合ページ(dashboard.html)v2 のレイアウト

- 全体 flex、font 14px。**左 304px**(side 背景・右 line 線)/ 右 main
- サイドバー上部(padding 16 16 12、gap 12): 「grill」(Mono 600 15px)+「質問票」(mute 12px)+ 右端「HH:MM 更新」(Mono 11px mute)。
  検索 input(input 背景・line 枠・radius 6)。プロジェクト select + `#issue` number(7em)。
  「状態」見出し(11.5px 600 sub)+ 3 列の状態チップ(line 枠 radius 8 で囲い、各セルに Mono 20px の件数(状態色)と「● ラベル」。
  押すとその状態だけ表示、もう一度で全部。単独表示中は selBg)。
  「種類」見出し + 種類チップ(Mono 12px、line 枠 radius 6。選択中は accent 塗り)。プロジェクトを選ぶとそのプロジェクトに存在する種類だけ出す
- 一覧(上部と line で区切り、padding 2 8 12): **状態ごとにグループ**(見出し: 7px ドット + ラベル + 件数 Mono mute)。
  項目は左 3px の線(現在の題材 = accent、他は透明)+ radius 0 6 6 0、padding 8 10。
  1 行目: タイトル 13.5px 500(2 行で省略)+「新着」バッジ(accent 塗り)+ 「n分前」(Mono 11px mute)。
  2 行目: meta「種類 · project · #issue · Rn」(Mono 11px mute、ellipsis)。アーカイブ済みは opacity .55。
  並びは 回答待ち → AI精査中 → 完了、同じ状態は更新が新しい順
- サイドバー下端: 「アーカイブ済み n 件 / 表示|隠す」(12px sub、上 line 線)。「隠す」操作は削除済み(アーカイブ表示の切替だけ)
- main 上部 50px(side 背景・下 line 線、padding 0 24): 「● 状態」(状態色 12px 600)+ meta(Mono 12px sub)+ 右端「MM/DD HH:MM 更新」
- 通知バー(selBg 背景): 「AI が質問票を更新しました。入力中の内容は下書きに残ります。」+「再読み込み」(accent 塗り)+「あとで」
- 本体は iframe。未レンダー時は中央に「まだレンダーされていません」(17px 600)+ `grill-<topic>.html`(Mono sub)+ 説明(sub 13.5px)
- スクロールバーは `scrollbar-width: thin; scrollbar-color: line transparent`
- 検証項目(設計の T1〜T11): 短いラベルが折り返さない / 不要な横スクロールなし / スクロールバーが背景になじむ /
  `#issue` のプレースホルダが切れない / ボタン文言が折り返さない / 狭い幅でも送信バーの操作が全部見える /
  同じ情報を 2 回出さない / 更新時刻がひと目で分かる / メモ欄は 1 行で始まり伸びる / 低い画面でも一覧が見える / 未レンダー時に次の動作が分かる
